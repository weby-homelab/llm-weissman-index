# Terminology

- **Candidate**: system being evaluated.
- **Baseline**: explicit reference system; baseline against itself is 100.
- **Workload**: benchmark/task/dataset and revision being measured.
- **Protocol**: repeatable measurement procedure and configuration.
- **Utility**: positive dimensionless quality value after a versioned transform.
- **Profile**: immutable normative policy for weights, required metrics,
  directions, transforms, gates, assumptions, and exclusions.
- **Comparison context**: exact semantic domain in which direct comparison is
  permitted.
- **Evidence class**: origin label for an observation, not a truth score.
- **Incomplete**: cannot be responsibly scored because a required fact is
  absent or disputed.
- **Ineligible**: observations are present but a quality gate or explicit
  zero-quality path prevents a numeric ranking score.
